VOICEVOX の CUDA ビルドを、WebAssembly で

GPU の無いブラウザで、CUDA 版 ONNX Runtime を動かします。カーネルはエミュレータの 外側 — コンパイル済みの WebAssembly — で計算されるので、合成が数時間ではなく数十秒で終わります。 仕組み

まず、CUDA ビルドの3ファイルを選んでください

このリポジトリは CPU 版しか持っていないので、CUDA 版は手元のものを使います。 ページの外には出ません。
voicevox_onnxruntime の CUDA 版 を展開した lib/ から、次の3つを選びます:

libvoicevox_onnxruntime.so.1.17.318 MB
libvoicevox_onnxruntime_providers_shared.so14 KB
libvoicevox_onnxruntime_providers_cuda.so440 MB

440 MB のうち 419 MB は GPU の機械語で、ここでは一度も実行されません。 tools/slim_provider.sh を通したものなら、中身がゼロになるだけで同じように動きます。
