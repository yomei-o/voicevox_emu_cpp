公式 VOICEVOX CORE を、ブラウザの中の x86-64 エミュレータで動かす

このページは VOICEVOX を移植していません。公式のバイナリをそのまま、 1 命令ずつ実行しています。ゲストは Linux x86-64 のプログラムで、 CPU だけが WebAssembly で書かれたソフトウェアです。

VOICEVOX の音声モデルは暗号化されていて、パッチの当たった voicevox_onnxruntime だけが開けます。だから「自前で書き直した推論エンジン」 ではどうやっても声は出ません。この方法はその逆で、 公式のランタイムに、公式のやり方で仕事をさせます。逆コンパイルも抽出もしません。

1. 材料を取ってくる

ONNX Runtime、CORE、ずんだもんの音声モデル、Open JTalk 辞書、 そして Debian の glibc 一式を、エミュレータの中のファイルシステムに置きます。 合計およそ 105 MB のダウンロード（展開後 190 MB）。一度きりです。

どのくらい時間がかかるのか

正直に言うと、とても遅いです。ネイティブなら 2 秒で終わることを、 インタプリタ方式のエミュレータは何千倍もかけてやります。 この数字はごまかしても仕方がないので、そのまま出します。

やることネイティブエミュレータ
(デスクトップ実測)
ONNX Runtime のロード0.0 秒4 秒
Open JTalk 辞書のロード0.0 秒0.2 秒
音声モデルの復号とセッション初期化0.6 秒約 8 分
推論（音声の長さに比例）1.5 秒下の実測を参照

ブラウザの中ではこれよりさらに遅くなります。タブを開いたまま待てる人向けです。 短い言葉ほど速く終わるので、まずは「あ」から試すのをおすすめします。

これは何をしているのか

ブラウザ → WebAssembly の x86-64 エミュレータ → 本物の ld-linux-x86-64.so.2 → libvoicevox_core.so → libvoicevox_onnxruntime.so。 動的リンク、IFUNC の解決、C++ の静的初期化子、そして ONNX Runtime のセッション初期化まで、 全部エミュレートされた命令の上で起きています。 同じエミュレータの上に voicevox_core と同じ C API も実装してあり、 そちらはネイティブのプログラムから普通に呼べます。

音声を利用する場合は VOICEVOX:ずんだもん のクレジット表記が必要です。 詳しくは 音源利用規約 を参照してください。 ソース: yomei-o/voicevox_emu_cpp
